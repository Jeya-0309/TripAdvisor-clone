# 🌍 TripAdvisor Clone

A responsive TripAdvisor website clone built using **HTML5 and CSS3**.  
This project recreates the layout and design of TripAdvisor with different travel sections, cards, responsive layouts, and a mobile-friendly navigation.

## 🔗 Live Demo

[Trip Advisor Website Link](https://jeya-0309.github.io/TripAdvisor-clone/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- Font Awesome
- Media Queries

## ✨ Features

- Responsive navigation bar
- Search section
- Trip recommendation section
- Interest section
- Outdoor activities section
- Travel spots section
- Donation section
- Inspiration section
- Sponsor section
- Travelers' Choice Awards section
- Responsive horizontal scrolling cards
- Responsive footer
- Mobile and tablet layouts

## 📱 Responsive Design

The website is responsive and adapts to different screen sizes:

- 💻 Desktop
- 📱 Tablet
- 📱 Mobile

CSS media queries are used to modify the layout, font sizes, card sizes, navigation, footer, and other sections for smaller screens.
